Job responsibilities At Glance:

  • Complete HANDS On Xilinx FPGA Flow, Vivado Flow and Protocompiler Tool flow or ZEBU Emulation flow is Essential to Have
  • Overall ownership of complete SOC deployment on Pre Silicon platforms on ZEBU
  • Get along with Design/SOC C/FW teams to identify actual FW implementation and plan/perform validation accordingly
  • Review SoC Verification plan for PCIe/LPDDR/ONFI sub system and Create/understand PCIe/LPDDR/ONFI Validation plan with SOC C, AE, FW teams
  • Develop understanding on SoC and perform Processor based SoC prototyping and Emulation using C/FW/AE Flow
  • Should be able to run SOC C based simulations for test case understanding and debug using VCS
  • Hands on HAPS 100, HAPS200, ZEBU, Palladium is most preferred, Hands on ZEBU is MUST to have
  • Work with overseas teams for PCIe/LP bring-up/debug
  • Should be writing the Verilog RTL when required, should be able to debug using Xilinx FPGA Vivado Flow

Proficiency in FPGA Debug Skills

  • Must have practical experience with Xilinx FPGA debug using Chipscope flow
  • Strong root-cause skills across hardware, RTL layers

Job Qualifications

  • Bachelors/Masters or equivalent experience in Engineering
  • Thorough Knowledge of ZEBU or Palladium Flow, Xilinx Ultrascale FPGA, Vivado Flow would be preferred.
  • Leverage AI-enabled tools to improve productivity and decision making
  • Good understanding on any of PCIe/NVME/LPDDR/ONFI Architecture
  • Minimum 12+ years of Processor based SoC, and hands-on ZEBU implementation experience
  • Good To Have - Knowledge of industry standard interfaces, such as ONFI, AXI, LPDDR, PCIE is an advantage
  • Strong Verilog Coding skills
  • Proven experience in scripting languages such as Python / Perl / TCL
  • Good written and oral communication
  • Excellent Great Teammate
  • Positive attitude, well-mannered mature behavior is must
