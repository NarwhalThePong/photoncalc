Sr Engineer, SSD Validation

Micron · Longmont-MAX- Office, CO · posted 2026-09-29

Our vision is to transform how the world uses information to enrich life for all.

Micron Technology is a world leader in innovating memory and storage solutions that accelerate the transformation of information into intelligence, inspiring the world to learn, communicate and advance faster than ever.

Design, develop, and automate test content for next-generation Micron solid-state storage products. In this role, required to contribute directly to feature validation, test method innovation, requirements analysis, and execution of validation workflows across multiple technologies and platforms. Required to collaborate closely with firmware, hardware, systems, and product teams to ensure SSD features meet industry standards, customer requirements, and high reliability expectations. This position required engineers motivated by hands-on development, deep debug, and building strong technical foundations in SSD architecture and validation methodology. Develop automated test cases for functional, performance, power, interoperability, stress, and negative-testing scenarios. Translate feature requirements, customer specifications, and industry standards into robust, reusable test content. Build and maintain test tools, utilities, and frameworks in Python or equivalent languages. Enhance automation workflows to improve coverage, reliability, and execution efficiency. Execute validation plans across multiple hardware, OS, and platform configurations. Investigate failures using logs, analyzers, debug tools, and structured root-cause methods. File well-documented issues and participate in triage discussions with cross-functional teams. Support qualification phases by providing accurate test results, metrics, and risk assessments. Contribute to CI-based automated regression systems and reporting dashboards. Improve test reliability, repeatability, and scalability across lab environments. Participate in design reviews, requirements discussions, and validation planning. Communicate progress clearly to senior engineers, leads, and cross-functional partners.


Employer will accept a Bachelor’s degree in Electrical Engineering, Computer Engineering, Computer Science, or related field.

 

Position requires:

1. Developing automated tests for storage devices or embedded systems, including creating new test cases, test flows, and reusable validation components

2. Python or related Scripting languages

3. Interpret and implement customer-specific test requirements, compliance documents, and feature specifications into executable validation content

4. Structured development methodologies: requirements breakdown, feature-based test planning, code reviews, CI/automation practices, and version control workflows

5. Test execution environments, including use of analyzers, logs, and debugging tools to validate features and diagnose failures

6. SSD fundamentals, including NAND behavior, basic FTL concepts, and high-level controller architecture
