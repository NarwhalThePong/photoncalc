Project Title 

MMP PPJ (part per jam) performance tracker enhancement 


Description 

The current PPJ performance tracker requires significant manual effort to update and monitor performance data. The dashboard is not fully dynamic because it relies on data manually downloaded into Excel. 

The tracking system that serves as the PPJ data source contains a large volume of information, making direct database retrieval difficult. As a result, engineers must manually download and update PPJ data. 

MMP also supports multiple product configurations across different test platforms, including SM3416/TW350HT and SM3316/TW322SM. Therefore, PPJ performance must be separated by test platform. 

PPJ alarm codes should also be used to identify faulty parts more effectively. 


Scope 

 Automatically convert PPJ data into trend charts using PowerBI 

  • Retrieve data from the database and automatically generate trend charts. 
  • Link equipment IDs with the corresponding alarm codes. 
  • Map alarm codes to the associated faulty parts. 

Supporting Team 

MMP Site Test Equipment Engineering


Deliverables 

Data Extraction and PPJ Trend Chart — Develop an automated process to extract PPJ data from the source database and convert it into clear trend charts. This will reduce manual Excel updates, improve data consistency, and allow engineers to quickly monitor PPJ performance movement over time. 

Faulty Part Identification by Alarm Code — Establish a mapping between alarm codes, equipment IDs, and related faulty parts. This will help engineers identify recurring hardware-related issues faster and support more effective troubleshooting and corrective action. 

Power BI Dashboard Enhancement — Enhance the dashboard to display PPJ performance by test platform, DID, equipment, and alarm category. The improved dashboard will provide dynamic filtering, better visibility of performance gaps, and faster drill-down capability for engineering review. 

Documentation and Adoption — Prepare user guidance, data refresh instructions, and maintenance documentation to support handover to Site Test Engineering users. This will ensure the tracker can be consistently used, maintained, and updated after deployment.


Stretch Goal:

Extend the Phase 1 automation into a more dynamic PPJ monitoring solution by enabling deeper analysis by test platform, DID, equipment ID, and alarm category. The stretch goal is to move beyond basic trend visualization and provide engineers with faster root-cause screening capability, so recurring performance losses or faulty part patterns can be identified earlier. 

If the data model is stable, additional enhancement can include automated refresh scheduling, exception highlighting for abnormal PPJ drops, and a summary view showing the top contributors impacting PPJ performance. This will help reduce dependency on manual review and improve response time during engineering investigations. 


Requirements 

Education 

  • Bachelor’s Degree in Electronics Engineering, Electrical Engineering, Computer Engineering, Data Science, Software Engineering, or a related discipline. 
  • Candidates with exposure to Artificial Intelligence, Data Analytics, Software Development, or Automation projects are preferred. 

Technical Skills 

  • Python programming and automation scripting. 
  • Data extraction, transformation, and consolidation. 
  • Data analysis and visualization. 
  • Database fundamentals and structured data management. 
  • Understanding of SQL or similar data-querying methods. 
  • Familiarity with Power BI or other dashboard development platforms. 
  • Experience with API integration, machine learning, or AI-assisted data extraction is an added advantage.
