Internship Project Outline Template

Project Title:
Module Site TE CATALYST Project

Description:
This project will establish a systematic and repeatable method to collect, validate, review, and report data during new Module Test tester setup and qualification. The intern will work with the Test Engineering team to convert fragmented setup records into a controlled data package with clear ownership, review gates, and approval evidence. An AI-assisted review concept will be piloted to identify missing data, unusual trends, and potential setup or qualification concerns for engineer verification. Final tool release decisions will remain with the responsible engineers.

The CATALYST Project need requalification process for SMT6 tester which needs relocation. Additional support is required to drive project completion, ensure compliance with operational requirements, and facilitate successful adoption by Site TEs across all qualification scenarios.
 

The ideal candidate should be pursuing or have obtained a Bachelor's degree in Electronics Engineering or Mechanical Engineering, with an interest in manufacturing, testing, and equipment qualification processes.

The ideal candidate should be pursuing or have obtained a Bachelor’s degree student in Electronics, Electrical, Mechatronics, Mechanical, Computer, Data Science, or Artificial Intelligence Engineering, with an interest in semiconductor manufacturing, equipment qualification, data analysis, and structured problem solving. The candidate should have basic skills in Excel; exposure to Python, SQL, Power BI, statistics, or machine learning is an advantage.


Scope:
- SMT6 Tester Qual (SOAK)
 

Supporting Team:

- Module Site TE (Jayanthan, Thina)

Deliverables:

• Define the required setup and qualification dataset for newly installed or transferred Module Test testers.

• Capture tester configuration, hardware and software baseline, calibration status, correlation results, product qualification results, yield, retest, test time, failure signatures, and issue closure evidence.

• Develop a structured review flow covering data readiness, engineering review, action tracking, final decision, and document retention.

• Pilot AI-assisted checks to flag incomplete fields, inconsistent entries, outliers, drift patterns, and recurring failure signatures for follow-up.

• Create a standard reporting view for daily review and final qualification summary.

Stretch Goal:

• Standard new tester setup data template and naming convention.

• Qualification readiness and review checklist with owners and status.

• Automated dashboard for data completeness, key metrics, actions, and release status.

• AI-assisted anomaly and missing-data review prototype with engineer validation.

• Final qualification summary template and reusable setup playbook.

Requirement

- Bachelor Degree in Electronics Engineering

- Bachelor Degree in Artificial Intelligence Engineering/Mechanical Engineering
