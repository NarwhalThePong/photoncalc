Project Title:

MMP Yield Performance Tracker and Dynamic Dashboard Automation Enhancement


Description:
This project aims to automate yield target extraction and implement a dynamic dashboard that automatically retrieves data from available sources.


Scope:

-Automate extraction of yield target data from TPD.
-Store yield targets in a structured database.
-Consolidate target and actual yield data in a single dashboard.
-Ensure data accuracy and consistency.

Supporting Team:
-Site Test Engineering

-IT Team
-Product Team

Deliverables:
-Data Automation

-Yield Calculation Enhancement

-Smart Data Integration
-Dashboard Improvement

-Documentation & User Adoption

Stretch Goal:
-Fully automate data collection and yield calculations with minimal manual effort.
-Automatically apply the correct yield calculation based on product configuration.

Requirement:
-Bachelor’s Degree in Electronics Engineering, Electrical Engineering, Computer Engineering, Data Science, Software Engineering, or a related discipline.

-Candidates with exposure to Artificial Intelligence, Data Analytics, Software Development, or Automation projects are preferred.
