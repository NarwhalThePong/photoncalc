Formula

FSR = c / (2 n L)    Δλ_FSR = λ² / (2 n L)
𝓕 = π (R₁R₂)^(1/4) / (1 − √(R₁R₂))    δν = FSR / 𝓕    Q = ν / δν
coefficient of finesse F = 4R / (1 − R)², R = √(R₁R₂)

Worked example

Two 99 % mirrors 50 mm apart in air: FSR = 3×10⁸ / 0.1 = 2.998 GHz, 𝓕 = π × 0.99^0.5 / 0.01 = 312.6, so the linewidth is 9.59 MHz. At 1550 nm the FSR is 0.0240 nm and Q ≈ 2.0 × 10⁷.

How it works

A Fabry-Pérot resonator transmits a comb of narrow peaks separated by the free spectral range. Finesse is the ratio of that spacing to the peak width and depends only on mirror losses here (no internal absorption). Higher reflectivity gives higher finesse and narrower lines.

For a confocal scanning interferometer the FSR is c/(4L), not c/(2L). For ring resonators use the round-trip length instead of 2L.

FAQ

What is the difference between finesse and coefficient of finesse?

Finesse 𝓕 = FSR/linewidth; the coefficient F = 4R/(1−R)² sets the Airy function contrast. 𝓕 ≈ (π/2)√F.

Should I use group index?

Yes, for dispersive media the FSR uses the group index n_g.

Does it include absorption?

No; add internal loss to the effective round-trip reflectivity.
